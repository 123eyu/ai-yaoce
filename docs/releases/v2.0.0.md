## 使用及边界

- 需要Windows x64与系统.NET Framework 4.8及以上；缺失时停止安装，不自动下载。安装包未商业签名。
- 升级前从托盘退出并卸载旧版；保留设置。存在同名程序、LICENSE或卸载器的目标目录拒绝覆盖。
- 程序目录为%LOCALAPPDATA%/Programs/ai-yaoce，设置目录为%APPDATA%/ai-yaoce。
- 六来源可独立启停；Codex/Claude读取本地计量日志，国产来源目前以配置审计为主，不冒充已完成计量适配。
- 不主动调用官方接口、不上传日志、不读取auth.json、不保存明文凭据；不含主动健康探测。
- 官订额度、余额、到期日仅在存在明确本地字段时显示，未知时隐藏；账号切换尚未交付。
- 配置审计不等于抓包，不能据此证明客户端实际上传或未上传用户信息。
- 仍需Windows物理设备、真实客户端/官订缓存与更大日志规模验收，因此仅发布预览版，不视为原始全部需求完成。
