# AI 遥测 Windows 轻量版 2.0.0

## 已批准方向
用户因107MiB安装包要求轻量化，并确认继续Windows原生托盘下一版。
比较：裁剪Electron不能消除其运行时；WebView方案仍需浏览器运行时；采用WinForms与系统.NET Framework4.8，不捆绑运行时。

## 范围
Windows x64，.NET Framework4.8及以上。macOS保持原版，不共用版本号。
原logo、产品名AI 遥测、程序目录ai-yaoce、设置目录%APPDATA%/ai-yaoce。
六来源启停；Codex/Claude增量本地计量；国产来源保留配置审计，未经确认的计量协议不假装支持。
官订字段只接受明确本地证据，无可靠字段就隐藏。没有安全账号适配器不显示切换入口。
不读取auth.json、密钥库、凭据正文，不存明文凭据；无HTTP/遥测/升级/主动探测代码。
隐私审计只显示端点origin和明确的布尔配置字段，不证明实际上传行为。

## UI
系统原生无动画托盘窗口；白色#FFFFFF、浅灰#F3F5F7、正文#243044、蓝色#176BD6、警示#8A5900。
Segoe UI/系统中文回退；左侧来源选择，右侧顶部渠道与本地状态；用量为紧凑四指标行，模型为表格，底部可选额度与审计列表。
键盘导航、可缩放窗口、DPI自适应；无渐变背景、无网页、无外部字体。托盘退出释放计时器与句柄。

## 数据与性能
后台串行扫描，UI不做日志文件IO。可选刷新30/60/120/300秒，默认60秒；暂停后不启动新扫描。
增量偏移、截断重置，mtime或首部/已读边界采样变化触发重读；不保证发现人为保留时间戳且只改未采样中段的改写。每轮最多400文件/8MiB解析预算，另有每文件数百字节一致性校验；每行最多256KiB，遍历最多5000项，跳过重解析点与网络盘。
只保留脱敏计量记录，单文件和全局有上限，滚动35天；达到上限提示统计不完整。
只写自有设置与价格规则，不写客户端目录。损坏配置保留文件并阻止静默覆盖。

## 安装与验收
NSIS每用户安装，无提权、无网络下载，保留用户设置；卸载只删除明确安装文件，不递归删除未知文件。
自动验收：解析器去重/增量/截断/超长行/凭据泄漏，六来源启停，安装后正常UI与托盘启动，退出重启，卸载清理。
合成大日志负载与空闲阶段记录CPU、工作集、私有内存、峰值；记录机器核数和样本时长，不外推物理设备。
截图不得包含真实用户数据。UI自动验收使用隔离本地日志目录，而非空白fixture快照。
安装包<5MiB、安装目录<10MiB、空闲私有内存<100MiB、空闲均值CPU<1%作为CI门槛。
